# Prácticas de JavaScript — 4to Medio

Ejercicios de JavaScript desarrollados para la asignatura, aplicando manipulación del DOM, estructuras de repetición y lógica de programación.

## Ejercicios incluidos

### 1. Suma de dos valores
Formulario que suma dos números ingresados por el usuario y muestra el resultado en pantalla.

### 2. Lenguajes de Programación
Recorre un arreglo con un ciclo `for`, mostrando cada lenguaje con su posición tanto en consola como en una lista visual.

### 3. Verificar Par o Impar
Captura un número desde un input y determina si es par o impar usando el operador módulo (`%`), mostrando el resultado en el DOM.

### 4. Calculadora de Descuento
Solicita precio original y porcentaje de descuento mediante `prompt()`, calcula el precio final y muestra un resumen de la compra en la página.

## Tecnologías
- HTML5
- CSS3
- JavaScript (vanilla)
