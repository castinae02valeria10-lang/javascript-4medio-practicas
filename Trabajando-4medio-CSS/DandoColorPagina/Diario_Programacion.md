# Día 2 - Flexbox

## Lo que aprendí


- Qué es Flexbox: Acomoda y ordena
Propiedad Importante: display:flex; (Le dice al navegador que organiza los elementos de esta caja usando Flexbox)

Dos Ejes: 
1.Main Axis (Horizontal) Eje Principal 
2.Cross Axis (Vertital) Eje Secundario

- Qué hace `display: flex`, (Contiene algo dentro, pasan a estar una al lado de la otra)
- Qué hace `gap`,(Es el espacio, entre las cajas)
- Diferencia entre crear elementos (HTML) y organizarlos (CSS).
HTML crea las cajas.
CSS decide cómo se ven.
Flexbox decide cómo se acomodan.

Son tres responsabilidades distintas.

## Lo que más me sorprendió

Con una sola línea (`display: flex`) las cajas cambiaron completamente de posición.
